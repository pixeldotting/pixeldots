## About

**pixeldots** is a Hyprland dotfiles setup designed around Google's **Material You** design language — soft tonal colors, rounded "cookie" shapes, and a clean, minimal look that stays consistent across the whole desktop.

> ⚠️ **Under construction** — things are still being set up and may change.
